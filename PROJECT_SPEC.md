# WETU STUDIO AI — Project Specification

## Supported project types
AD, SHORT, FILM, SERIES, EPISODE, MUSIC_VIDEO, SOCIAL.

## Project lifecycle
IDEA → PREPRODUCTION → GENERATION → EDITING → QA → READY → PUBLISHED

## Project data
Identity, type, synopsis, bible, characters, locations, visual style, script, storyboard, generations, audio, edit timeline, exports, provenance, status and history.

## Generation record
Every generated asset should retain provider, model/version when available, prompt/reference metadata, creation time, input references, output hash and project association.

## Non-goals
- No promise of automatic cinematic quality.
- No automatic publication without user validation.
- No storage of provider secrets in source code.
- No immediate proprietary model training requirement.
