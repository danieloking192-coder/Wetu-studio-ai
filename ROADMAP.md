# WETU STUDIO AI — Roadmap

## Phase 1 — Foundation
Repository structure, project schema, configuration, security baseline and tests.

## Phase 2 — Preproduction
Project Studio, Script Engine, Character Engine, World/Style Bible and Storyboard.

## Phase 3 — Generation
Video, image, voice and audio provider adapters with job orchestration.

## Phase 4 — Postproduction
Timeline, editing, captions, sound mix, continuity and quality gates.

## Phase 5 — Product
Advertising Studio, Film/Series Studio, templates, project history and exports.

## Phase 6 — Application
Web/mobile interface, authentication, project storage, usage controls and resilient API.

## Phase 7 — Production
Observability, security review, performance tests, provider fallback, release builds and publishing.

### Rule
No feature is considered production-ready without execution evidence, tests and documented limitations.
