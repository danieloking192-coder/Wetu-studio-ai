# WETU Animation Production

Animation is a first-class production medium, alongside live-action image/video/audio.

Supported production media:
- 2D animation
- 3D animation
- anime-oriented animation
- toon/cartoon
- stop motion
- hybrid animation

Animation has its own Style DNA: visual language, camera language, motion language and lighting language. This prevents WETU from treating animation as a normal photorealistic prompt.

The system supports original animated universes and can reproduce a requested high-level animation language through structured attributes. It does not require copying a specific copyrighted character, scene or franchise identity.

Flow:

Character DNA + World DNA + Animation Style DNA + Scene Memory
→ Animation Request → Provider → Animation Asset → Animation QA → Timeline → Export.
