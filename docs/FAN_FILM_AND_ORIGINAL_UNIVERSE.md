# WETU — Fan Film & Original Universe Modes

WETU deliberately separates two production modes.

## FAN_FILM

Use this mode for a short fan production that references an existing work.

Example: a Naruto Shippuden fan short can explicitly register Naruto Uzumaki, Sasuke Uchiha, Sakura Haruno or Kakashi Hatake as referenced characters. The production memory records the source work and provenance.

## ORIGINAL

Use this mode for WETU's own long-form animated universe. It can contain original characters, clans/factions, power systems, cities, languages, seasons, episodes, character arcs and persistent animation Style DNA.

An ORIGINAL production rejects IP-character references at the model layer so that a fan-film project cannot silently contaminate the original universe.

## Short-film workflow

1. Create project.
2. Select FAN_FILM.
3. Register referenced characters.
4. Write the original short-film scenario.
5. Build scenes and animation requests.
6. Generate through a connected provider.
7. Run Animation QA and Continuity QA.
8. Assemble the timeline.
9. Export the production bundle.

## Important boundary

Fan-film references are explicit provenance records. WETU does not automatically copy protected source artwork, scripts or scenes. Actual rendering still requires a connected media provider capable of the requested image/video/audio generation.
