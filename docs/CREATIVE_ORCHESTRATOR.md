# WETU Creative Orchestrator

The Creative Orchestrator is the high-level planning boundary of WETU.

**Brief → persistent production context → scene plans → realism validation → renderer contract.**

It deliberately does not pretend to render media. A real image/video/audio provider must be connected for actual generation.

The orchestrator preserves:
- Character DNA
- World DNA
- Scene Memory
- Production Memory
- Emotion & Atmosphere
- Realism QA
- provider neutrality

This is the application-level layer above the lower-level creator core.
