# WETU Studio AI — Format Workflows Policy

Status: CORE PRODUCT DESIGN.

## Advertising
Brand brief → product/character identity → script → storyboard → generations → variants → legal/rights checks → edit → platform exports.

## Short film / film
Idea → story → character/world bible → scenes → storyboard → generation → continuity → audio → edit → QA → master.

## Series / episode
Series bible → recurring characters/locations → episode script → shot plan → generation → continuity against prior episodes → edit → QA → episode master.

## Social
Idea → hook → vertical/horizontal/square composition → short generation → captions/audio → platform variants → export.

The same underlying entities remain reusable across formats; only the presentation and constraints change.
