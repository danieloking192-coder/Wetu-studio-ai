# WETU STUDIO AI — World, Cities & Realistic Architecture

Status: CORE PRODUCT DESIGN

WETU supports multiple fictional or reference-based cities and locations inside one project. A location keeps its identity, geography/context, architecture, environment and landmarks so scenes can return to the same place consistently.

## Realistic houses
Houses are structured assets with exterior, interior, architectural style, materials, rooms and realism notes. The goal is cinematic, physically coherent environments with persistent design references.

## City continuity
A city/location ID is reused across scenes. Changes must be explicit so the same environment does not silently change between shots.

## Rights
Reference-based real locations may require appropriate rights/licensing for commercial use depending on the source material and use case. WETU must preserve provenance rather than inventing clearance.

## Provider independence
WETU stores structured world metadata and references; connected image/video providers remain responsible for the actual visual generation capability.
